# Merge Two Sorted Lists

**Difficulty:** Easy  
**Link:** [https://leetcode.com/problems/merge-two-sorted-lists/](https://leetcode.com/problems/merge-two-sorted-lists/)

---

## Problem Statement

```
Title: Middle of the Linked List

Description:
Given a linked list, find the middle element. If the length of the linked list is even, return either the first or second middle element.

Examples:

1. Input: 1 -> 2 -> 3 -> 4 -> 5
   Output: 3

2. Input: 1 -> 2 -> 3 -> 4
   Output: 2

3. Input: 1
   Output: 1

Constraints:
- The linked list only contains positive integers.
- The length of the linked list is at most 10^5.
```
