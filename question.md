## Problem Statement

**

**Title:** Find Pair with Complement Sum

**Description:** Given an array of integers and a target sum, determine if there exists at least one pair whose elements sum up to the target. If such a pair is found, return True; otherwise, return False.

**Examples:**
1. Input: arr = [2, 3, 5], target = 8
Output: True (because 3 + 5 = 8)

2. Input: arr = [10, 20, 30], target = 40
Output: False (no pair sums up to 40)

3. Input: arr = [1, 2, 3, 4, 5], target = 7
Output: True (because 2 + 5 = 7 or 3 + 4 = 7)

**Constraints:** 
- The array size is within the range of 1 <= N <= 10^5.
- The sum of elements in the array is within the range of 1 <= sum(arr) <= 10^9.
