## Problem Statement

**Title:** Remove Invalid Parentheses
**Description:** 
Given a string s containing only valid parentheses (i.e., `(` and `)`), return the smallest possible string that contains every substring of `s` in order, as if every open parenthesis has been matched with a corresponding close parenthesis.
**Examples:**

1. Input: `"lee(t(c)o)de)"`, Output: `"lee(t(c)o)de"`
2. Input: `"(a)()())"`, Output: `""`
3. Input: `"no())()"`, Output: `""`

**Constraints:** 

* 1 <= s.length <= 10^4
* `s` only contains `(` and/or `)`
* The input string does not contain any nested parentheses.
