# Quicksort on singly-linked list

**Difficulty:** Hard  
**Link:** [https://www.geeksforgeeks.org/quicksort-on-singly-linked-list/](https://www.geeksforgeeks.org/quicksort-on-singly-linked-list/)

---

## Problem Statement

```
Title: Quick Sort Linked List
Description:
Write a function that takes the head of a singly linked list as input and returns the sorted list. The sorting algorithm used should be Quick Sort.
Constraints:
- 1 <= N <= 10^5 (number of nodes in the linked list)
Input/Output Examples:

Example 1:
Input: 
Linked List: 4 -> 2 -> 9 -> 6
Output: Linked List: 2 -> 4 -> 6 -> 9

Example 2:
Input: 
Linked List: 10 -> 5 -> 8
Output: Linked List: 5 -> 8 -> 10

Example 3:
Input: 
Linked List: 1 -> 3 -> 2
Output: Linked List: 1 -> 2 -> 3

```
