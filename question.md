## Problem Statement

**Title:** Rearrange Linked List to Separate Even and Odd Nodes

**Description:** 
Given the head of a singly linked list, rearrange the list in place so that all nodes containing even values appear before nodes containing odd values. Return the head of the modified linked list.

**Examples:**

1. Input: 
    head: 2 -> 1 -> 4 -> 3

    Output: 
    head: 2 -> 4 -> 1 -> 3

2. Input: 
    head: 1 -> 2 -> 3 -> 4 -> 5

    Output: 
    head: 2 -> 4 -> 1 -> 3 -> 5

3. Input: 
    head: 1 -> 3 -> 5 -> 7 -> 9

    Output: 
    head: 1 -> 3 -> 5 -> 7 -> 9

**Constraints:**

* The linked list is a singly linked list.
* Each node in the linked list contains an integer value.
* The values in the linked list are in the range [0, 10^9].
* The length of the linked list is at most 10^5.
* The linked list is non-empty.
