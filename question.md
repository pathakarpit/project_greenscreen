## Problem Statement

**Title:** Divide Linked List at Even Nodes

**Description:** Given a linked list, divide it at even nodes and return the new head.

**Examples:**

1. **Example 1:** Input: `17->15->8->9->2->4->6`, Output: `2->4->6->17->15->8->9`
2. **Example 2:** Input: `10->20->30->40->50`, Output: `10->20->30->40->50`
3. **Example 3:** Input: `1->3->5->7->9`, Output: `1->3->5->7->9` (no change since no even nodes)

**Constraints:**

1. The linked list is non-empty.
2. The linked list contains nodes with positive integer values.
3. The linked list is singly linked (no self-references).
4. The linked list is not cyclic (no nodes point to themselves).
5. The maximum value of any node is `10^9`.

Note: The above constraints are reasonable based on the given problem description and code. They ensure that the problem is well-defined and can be solved efficiently.
