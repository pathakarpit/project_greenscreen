## Problem Statement

**Title:** Separate Even and Odd Nodes in a Linked List
**Description:** Given the head of a singly linked list, write a function to separate even and odd nodes in the list, such that all even nodes are moved to the end of the list, and the order of even and odd nodes remains preserved.
**Examples:**
1. Input: head = [1, 2, 3, 4, 5], Output: [1, 3, 5, 2, 4]
2. Input: head = [2, 1, 3, 5, 6], Output: [1, 3, 5, 2, 6]
3. Input: head = [1, 2, 3, 4, 5, 6], Output: [1, 3, 5, 2, 4, 6]
**Constraints:** 
- The linked list may contain multiple even and odd nodes.
- The head of the linked list is always provided as input.
- The order of even and odd nodes should remain preserved.
- The time complexity of the function should be O(n), where n is the number of nodes in the linked list.
- The space complexity of the function should be O(1), excluding the space required for the linked list nodes.
- The function should not modify the input linked list.
